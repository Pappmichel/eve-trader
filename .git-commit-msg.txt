Deployment successful - document real gotchas, remove HANDOFF.md

First real Oracle Cloud deployment (VM.Standard.E2.1.Micro, eu-frankfurt-1)
completed end-to-end 2026-08-16: app is live, access gate confirmed working
with a real EVE SSO login. deploy/README.md updated with what actually
went wrong along the way, not just theory:

- Two separate firewall layers both need port 80/443 open: Oracle's
  Security List (cloud-level) AND the VM's own local iptables
  (Oracle's stock Ubuntu images default to SSH-only inbound) - missing
  either one looks identical from the outside (services show "active
  (running)", curl works locally, nothing reachable externally).
- A manually-created VCN/subnet needs its own Internet Gateway + a
  0.0.0.0/0 route table entry - the Console wizard didn't reliably set
  this up for us, same "looks fine, unreachable" symptom.
- E2.1.Micro isn't available in every Availability Domain within a
  region - check with `oci compute shape list` before launching, not
  after a confusing NotAuthorizedOrNotFound.
- SESSION_SECRET_KEY is easy to miss in a manual nano edit of .env -
  doesn't fail until the first login attempt (Internal Server Error).
  Documented the append-instead-of-edit workaround + a verification grep.

HANDOFF.md deleted per its own stated lifecycle ("delete once the Oracle
VM is up and deployed") - that's now true.
